# To-Do App (GitHub Pages)

A small, browser-based to-do list app with persistent tasks and a clean UI.

## Features

- Add tasks with a priority selector: **High / Medium / Low**
- Visual priority badges with different colors
- Mark tasks as completed (with live counters for *Active* and *Completed*)
- Edit existing tasks (text + priority)
- Delete individual tasks
- **Clear completed** (disabled when there are no completed tasks)
- **Clear all** with a confirmation prompt
- Floating pending-task dock with a live unfinished count
- Floating pending-task panel sorted by priority, with one-click completion
- Optimized floating panel preview that shows the top 5 most urgent tasks first
- Floating panel priority summary chips for **High / Medium / Low**
- Expand / collapse controls for the floating panel when there are many unfinished tasks
- Click-outside / Escape support to quickly dismiss the floating panel
- Import remote to-do items from a JSON URL
- Import support for common task shapes such as `text`, `title`, `name`, `task`, and `content`
- Friendly empty state when there are no tasks
- Tasks are saved in `localStorage`, so refreshing the page won’t lose your list

## URL import

The app accepts JSON from a URL and will import:

- an array of strings, or
- an array of objects with fields like `text`, `title`, `name`, `task`, `priority`, `completed`, or
- an object containing one of these arrays under keys such as `tasks`, `todos`, `items`, `data`, `results`

Note: the target URL must be publicly reachable by the browser and allow cross-origin requests.

## Floating panel

The floating panel is designed to surface unfinished work quickly:

- tasks are ordered by priority from **High** to **Low**
- the default view focuses on the top 5 most urgent unfinished tasks
- high-priority tasks are visually emphasized
- you can mark a task as done directly from the panel and it disappears immediately
- if there are more tasks, the panel can expand to show everything
